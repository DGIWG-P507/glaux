### 4.2 A fifth source for the F-03 cache instance, from the test side

IDR-055 is the fifth accepted-corpus report to state the cache and validator rule, and the first to state it as a **testable leakage surface** rather than an architectural obligation:

- §8: "Cursors and validators bind the authorized view, policy version, principal/client and query/filter; cross-principal or cross-policy reuse is rejected without revealing why."
- §9 leakage inventory explicitly includes "status, headers, response length, **cache validators** and timing."
- §5.1, row `SEC-POLICY-VIEW`: the negative case is "hidden row changes count/page/latest/**ETag**", with the expectation that the authorized view precedes the query.
- §14.4 proof 4: twin-world tests must prove the declared public projection "including count, page, extent, latest, **cursor and ETag**" does not change with hidden facts.

The F-03 instance's recorded remedy already asks for the cache and validator channel to be added to the Guide's disclosure-channel test list at line 1019, which currently names links, schemas, counts, latest selection and events. IDR-055 supplies exactly that test formulation. Because this report is unaccepted, it is recorded as corroboration of an instance that already rests on four accepted reports, not as independent authority. Substance and remedy unchanged.
